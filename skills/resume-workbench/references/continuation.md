# 以最新 Word 续编

用户修改后的 Word 是内容和格式基准。不存在历史 JSON 或版本库也可操作，不要求重新访谈重做。先检查最新版，复制到新目录，执行明确修改，保留原文件哈希。

精确替换输入为 UTF-8 JSON 数组：

```json
[{"old": "原来的完整文案", "new": "用户指定的新文案"}]
```

`continue` 能跨 run 替换文本，保留其他段落、表格与样式；原文不存在或重复而不能唯一判断时返回需要更精确修改，不能猜位置。新的 Word 还要回读正文检查，不从旧 payload 重建。

多段新增、移动栏目或表格结构等复杂编辑可由文档工具在副本上完成。复制与编辑一样要保留原件，宏、安全及文件检查仍适用。将新事实列为待确认差异，格式变化不产生新事实。

重新从本次最终 Word 转换 PDF，记录来源哈希。旧 PDF 即使名称一样也可能过期。保存新的版本记录和审阅记录；缺历史只影响自动资料差异比较，不影响 Word 副本修改与导出。
